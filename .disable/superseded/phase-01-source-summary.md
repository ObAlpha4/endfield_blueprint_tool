## 4. 配方摘要

以下按制作设备和功能归纳；括号内是源表行号，便于回查。所有反应时间均为源表中的秒数，物料数量为每次配方的数量。

### 4.1 资源采集与环境

- 电驱矿机产出源矿（60 秒，540 个，2）；二型电驱矿机产出蓝铁矿（60 秒，120 个，3）；水驱矿机产出赤铜矿（60 秒，510 个，4）。
- 气体收集泵产出惰气（60 秒，460 个，5）或息壤气（60 秒，150 个，6）。
- 水泵产出清水（1 秒 1 个，7）；二型耐酸水泵产出沉积酸（1 秒 1 个，8）。
- 气体散布机消耗 6 个惰气/水蒸气/酸气/息壤气，60 秒提供稳定/湿润/酸性/息壤环境（126-129）。

### 4.2 精炼、粉碎和研磨

- 精炼炉（9-33）：蓝铁矿或蓝铁粉末 -> 蓝铁块；紫晶矿或紫晶粉末 -> 紫晶纤维；源矿或晶体外壳粉末 -> 晶体外壳；致密晶体粉末 -> 密制晶体；致密蓝铁粉末 -> 钢块；高晶粉末 -> 高晶纤维；致密碳粉末 -> 稳定碳块；致密源石粉末 -> 致密晶体粉末；源石粉末 -> 晶体外壳粉末；六类植物及其粉末 -> 碳块、碳粉末或致密碳粉末。
- 液体模式精炼炉：赤铜矿 + 清水 -> 赤铜块 + 污水（2 秒，34）。
- 粉碎机（35-46）：赤铜块、蓝铁块、紫晶纤维、源矿、碳块、晶体外壳、荞花、柑实、砂叶、酮化灌木、锦草、芽针 -> 对应粉末/碎料。
- 研磨机（104-110）：两份目标粉末 + 一份砂叶粉末 -> 一份致密蓝铁粉末、高晶粉末、致密源石粉末、致密碳粉末、致密晶体粉末、细磨荞花粉末或细磨柑实粉末。

### 4.3 零件、容器、种植和废水

- 配件机（47-53）：蓝铁块、紫晶纤维、钢块、高晶纤维、赤铜块、赫铜块、灼铜块 -> 对应零件。
- 塑形机（54-59）：两份金属/纤维输入 -> 对应瓶；其中赤铜块配方的产物名称在原表也是“赤铜块”，需要确认是否为原始数据错误或特殊规则。
- 气体模式塑形机：两份赤铜块 + 惰气 -> 赤铜耐压罐（60）。
- 种植机（61-66）：种子（部分配方另需清水）-> 荞花、柑实、砂叶、酮化灌木、锦草、芽针。
- 采种机（67-72）：对应植物 -> 对应种子。
- 废水处理机（73-75）：污水、壤晶废液、惰性壤晶废液各可作为单输入配方，但输出栏为空，具体产物/处理结果未在表中给出。

### 4.4 装备原件、灌装和封装

- 装备原件机（76-82）：晶体外壳/密制晶体/赤铜零件/赫铜零件/灼铜零件等，与紫晶纤维、蓝铁块、高晶纤维、息壤或重息壤组合，产出对应装备原件。
- 灌装机（83-88）：瓶 + 柑实粉末或荞花粉末 -> 普通、优质或精选罐头/胶囊。
- 液体模式灌装机（89-92）：蓝铁瓶或赤铜瓶 + 芽针溶液或锦草溶液 -> 装液体的瓶。
- 封装机（93-103）：零件与植物粉末、源石粉末、致密源石粉末、装液体瓶、息壤或壤晶组合，产出工业爆炸物、谷地/武陵电池、针剂、软饮和分离芯。

### 4.5 反应、提纯和天有洪炉

- 反应池（111-118）：芽针粉末/锦草粉末/息壤/重息壤/赤铜粉末等与清水、沉积酸或污水反应，产出芽针溶液、锦草溶液、液化息壤、液化重息壤、赤铜溶液，以及壤晶废液、惰性壤晶废液、壤晶、赫铜溶液、污水等副产物。
- 天有洪炉（119-121）：稳定碳块或碳块 + 清水 -> 息壤；息壤 + 壤晶废液 -> 重息壤。第 120 行明确要求稳定环境。
- 液体模式提纯机（122-123）：惰性壤晶废液 -> 壤晶废液 + 清水；赤铜溶液 -> 赫铜溶液 + 沉积酸。
- 气体模式提纯机（124-125）：息壤气或气态赤铜 + 分离芯 -> 重息壤气或气态赫铜；明确要求稳定环境。
- 气体反应炉（130）：气态赫铜 + 息壤气 -> 气态灼铜；明确要求酸性环境。

### 4.6 液气与固气转换

- 液气转化机气体产出（131-136）：清水、沉积酸、液化息壤、液化重息壤、赤铜溶液、赫铜溶液 -> 水蒸气、酸气、息壤气、重息壤气、气态赤铜、气态赫铜。
- 液气转化机液体产出（137-142）：水蒸气、酸气、息壤气、重息壤气、气态赤铜、气态赫铜 -> 清水、沉积酸、液化息壤、液化重息壤、赤铜溶液、赫铜溶液。
- 固气转化机气体产出（143-147）：息壤、重息壤、赤铜块、赫铜块、灼铜块 + 息壤气 -> 对应气体。
- 固气转化机固体产出（148-152）：息壤气、重息壤气、气态赤铜、气态赫铜、气态灼铜 -> 对应固体。
- 上述转换配方的催化剂列为液化息壤或息壤气，催化剂列的数值是固定消耗量，源表中对应数值为 6；该消耗量随每次配方固定消耗，不能解释为周期、加速倍率或独立供给速率。

### 4.7 速率换算边界

时间统一使用秒；物品数量单位为“个”，液体和气体数量单位为“滴”。单机理论速率统一按 `数量 * 60 / 时间` 换算为每分钟，其中物品为个/分钟，液体和气体为滴/分钟。催化剂作为每次配方的固定消耗量参与物料平衡。

## 5. 规则摘要

### 5.1 基地、仓储与外部资源

- **R-001** 资源开采设备放在蓝图规划范围外。源矿、蓝铁矿、赤铜矿从仓库取出；清水、沉积酸用水泵；惰气、息壤气用气体收集泵从基地外开采。蓝图需预留外围管道接口或内部未连接暗管出口。
- **R-002** 每基地仓库存取线源桩最多 2 个。
- **R-003** 主基地规划面积为 80x80，仓库存取线基段最多 5 个；副基地规划面积为 50x50，仓库存取线基段最多 12 个。
- **R-004** 每个基段必须连接源桩，或连接到已连接源桩的基段。
- **R-005** 仓库取货口和存货口的 3 宽普通面必须贴靠源桩或基段。
- **R-006** 每基地必须且只能有 1 个协议核心。
- **R-007** 取货口和协议核心取货口需标记物品；每个标记取货口只能取一种物品，取货速度 30/min。
- **R-008** 存货口和协议核心存货口将物品返回仓库，存货速度 30/min。

### 5.2 传送带

- **R-010** 设备之间至少使用 1 单位传送带连接出入口；每单位占 1x1，最大连续长度 80。
- **R-011** 运输方向单一，可转弯；转弯弯角占 1x1。
- **R-012** 最大速度 30/min，超出部分限速到 30/min。
- **R-013** 分流器一进二或一进三；汇流器最多三进一；各占 1x1。
- **R-014** 垂直交叉使用物流桥，占 1x1；桥上下左右一格范围内方向保持不变，连接转弯时靠桥的半段方向保持不变。
- **R-015** 反向传送带不能同格；两个转弯弯角不能同格。
- **R-016** 物品准入口只能通过被标记的一种物品，最大 30/min；限速范围 0 到 30/min，步长 6/min，端点包含。
- **R-017** 传送带、分流器、汇流器、物流桥、物品准入口不能与仓储存取、基础生产、合成制造、电力供应设备重叠。
- **R-018** 传送带可在不超过上限时经汇流器运输多种物品；可用分流器加物品准入口拆分混带。

### 5.3 管道、混管与暗管

- **R-020** 设备之间至少使用 1 单位管道连接出入口；每单位占 1x1，最大连续长度 80；最大速度 120/min，超出部分限速到 120/min。
- **R-021** 管道方向单一，可转弯；转弯弯角占 1x1；反向管道或两个弯角不能同格。
- **R-022** 管道分流器一进二或一进三；管道汇流器最多三进一；各占 1x1。
- **R-023** 垂直交叉使用管道桥，占 1x1；桥上下左右一格范围内保持方向不变。
- **R-024** 管道准入口只能通过被标记的一种液体或气体，最大 120/min；限速范围 0 到 60/min，步长 6/min，端点包含。
- **R-025** 管道和管道准入口可与传送带、分流器、汇流器、物流桥、物品准入口同格；管道分流器、管道汇流器、管道桥不可同格。
- **R-026** 管道、管道分流器、管道汇流器、管道桥、管道准入口不能与仓储存取、基础生产、合成制造、电力供应设备重叠。
- **R-027** 管道可混运液体、气体及液气混合物；混管中途需按每隔 1 或 2 单位的条件使用管道准入口“断开”，交叉处的管道桥也可断开。
- **R-028** 管道汇流器入口存在先接先高优先级；可在入口增加管道分流器降低或提高相关通路优先级，具体适用情况取决于单种流体、两种流体或三种流体混流。
- **R-029** 两种或三种流体混流拆分时，出口准入口数量必须与需要完全分开的流体种类数一致；规则明确不存在四种及以上流体汇流。
- **R-030** 一对暗管或一对多口暗管只能运输一种液体或气体，不可混流；多口暗管入口接暗管出口可模拟汇流，多口暗管出口接暗管入口可模拟分流。

### 5.4 缓存、溢流和反应池

- **R-040** 协议储存箱可在仓储模式、断电状态下作为缓存；有 6 个缓存格，每格一种物品，每格最多 50 个。
- **R-041** 协议储存箱返回仓库时每 10 秒将全部缓存返回；作为产物返回使用时规则建议一个箱子只存一种物品，但“建议”不是硬约束。
- **R-042** 设备出口有多通路时，达到最大运输速度或连接设备缓存已满的通路会溢流到其他通路。
- **R-043** 设备物品出口或缓存协议储存箱直接接单/多条传送带加汇流器时，汇流器通路通常优先级更低；可增加物流元件进一步降低优先级。
- **R-044** 有两个液体或气体出口的设备，一个出口直连管道、另一个接管道汇流器时，汇流器通路优先级更低。
- **R-045** 基础生产、合成制造、热能池生产时，每种配方的每种原料最多输入 50 个。
- **R-046** 反应池有 5 个缓存格，扩容反应池有 8 个；每格只能存一种物品或液体，最多 50 个；二者可同时进行多个配方反应，并可选择两种液体和一种物品输出。

### 5.5 供电和环境

- **R-050** 供电桩占 2x2，为 12x12 范围内设备供电；设备至少一格在范围内即可；供电范围可相交。
- **R-051** 除协议核心、气体散布机、热能池、仓储存取设备外，其他设备都需要供电桩。
- **R-052** 气体散布机占 3x3，为 13x13 范围内设备提供环境；设备必须完全位于范围内；两个气体散布机范围不可相交但可相切。
- **R-053** 净水节点不纳入蓝图摆放规划；全局只有一个，最多处理 360/min 污水并返回 12/min 壤晶废液。接入时蓝图只预留暗管入口和暗管出口。
- **R-054** 热能池本身不消耗电量；内部电池缓存最多存放 50 个同种类电池，电池消耗速率按《发电对照.xlsx》对应条目的燃烧时间执行。

## 7. 明确歧义和数据问题

以下问题必须在进入数据标准化或编码前确认：

1. 设备宽高的坐标含义、坐标原点、整数网格原点和旋转后的接口离散映射未定义；已确认设备只能顺时针旋转 90 度、180 度或 270 度，不能镜像。
2. 接口串中同一面的接口顺序如何对应设备边缘格子未定义；`n` 是否真的占据接口位置还是只表示可贴靠的普通面，需要确认。
3. 设备表与规则分类之间没有完整的逐项映射；规则提到的传送带、分流器、汇流器、桥、准入口、供电桩等没有在设备规格表中给出尺寸和接口。
4. 规则要求“至少 1 单位”连接和“最大长度 80”，但长度是按连续段、设备间路径、还是单个物流元件计算未定义；桥、分流器、汇流器是否重置长度未定义。
5. 管道混流“每隔 1 单位或 2 单位断开”的选择条件和断开后的连接语义未定义；优先级调整中“增加分流器以降低/提高优先级”的具体拓扑未给出。
6. 传送带/管道的“方向相反”“垂直交叉”“桥附近一格”的几何判定细节未定义，尤其是多格设备接口与转弯方向。
7. 设备环境的作用时机未定义；气体散布机配方中环境气体消耗 6 个/60 秒，但设备需要环境的持续判定方式未给出。
8. `气体散布机` 与规则正文中的 `气体扩散机` 应视为同一设备吗？需要确认名称规范。
9. `协议储存箱` 与规则正文中的 `协议存储箱` 应视为同一设备吗？需要确认名称规范。
10. 废水处理机三行只有输入和时间，没有输出；净水节点又是独立的可选项，二者关系无法从文件确定。
11. 反应池和扩容反应池“可同时进行多个配方”没有给出同时运行数量、配方选择结构和各缓存格的输入输出绑定方式。
12. 规则提到普通模式、液体模式和气体模式，但同一模式是否由设备类型名称完全决定、是否可切换，未定义。
13. 设备表中的若干名称有空格/换行差异，且塑形机“赤铜块 -> 赤铜块”看似异常；需要给出规范名称和修订确认。
14. 供电桩的 12x12、气体散布机的 13x13 是以设备中心、占地外框、覆盖格还是曼哈顿范围计算未定义；边界是否包含也未定义。
15. 仓库取货口、存货口、协议核心取货/存货口的具体接口编号和传送带连接方向未定义；“3 宽普通面贴靠”中的贴靠位置也未定义。
16. 建造顺序、材料清单字段、蓝图 JSON/字符串格式、目标产物选择多个配方时的决策规则，四份源文件均未定义。

## 8. 当前假设

仅作为本阶段文档的阅读假设，不得直接固化到实现：

- 所有源文件中的中文名称在确认后将有一个规范名称；空格和换行只是录入或显示差异。
- 接口串按 `si`、`so`、`fi`、`fo`、`gi`、`go`、`n` 进行最长匹配分词。
- 配方速率使用 `数量 * 60 / 秒数` 换算为每分钟；物品单位为个，液体和气体单位为滴；催化剂是每次配方的固定消耗量。
- 主基地规划边界为 80x80，副基地规划边界为 50x50；基地类型还分别影响仓库存取线基段上限，除非后续规则文件补充其他差异。
- 发电功率和设备耗电功率统一以 kW 表示；燃烧时间以秒表示；热能池不消耗电量，每种电池最多缓存 50 个，并按发电对照表燃烧时间消耗。
- 源文件未说明的几何、容量、功率和导出格式不进入第一版实现假设。
