# 物流设备与存取线连接（由附图标定）

状态：几何关系已标定；符号辨认已完成（见 §4）

本文把 B-9、B-10 细化成可实现规则（原始记录见 `.disable/history/round2-b-class-resolutions.md` §7、§8）。标定依据是用户提供的两张实机截图（物流设备示例图、基段与源桩关系图）。

## 1. 物流设备的建模方式（B-9）

### 1.1 已确认的性质

1. **全部 1×1 占地**（供电桩 2×2 是唯一例外，见 B-9 表）。
2. **没有固定的四面接口串**。它们是**朝向可变器件**：
   同一张图里出现了直段、弯段、三通、桥、准入口等不同形态，说明**形状由设备类型决定，朝向由 `rotation` 决定**，端口位置随旋转实例化。
3. **端口数由类型决定**：

   | 类型 | 端口数 | 端口所在面 |
   |---|---:|---|
   | 直段（传送带 / 管道） | 2 | 一组**相对**面 |
   | 弯段 | 2 | 一组**相邻**面 |
   | 分流器 / 汇流器 | 3 或 4 | 一进二出 / 二进一出（或三出 / 三进，由走向决定） |
   | 物流桥 / 管道桥 | **4** | **四个面**（两条正交线各占 2 口） |
   | 物品准入口 / 管道准入口 | 2 | 一组相对面 |

   因此 `DeviceType` 对这 12 种设备**不能套用「北/南/西/东固定串」的表结构**，需要「按类型 + 旋转生成端口」的规则。
   （读数 = 规则段 2 的 10 种器件 + 物品弯段 + 管道弯段；用户确认**两种弯段分开计算**。）

### 1.2 两种物流网络在图上完全区分

- **物品网络 = 黄色**：1×1 的扁平方块，连接处**直角相接**；块内有**人字形箭头**指示流向。
- **管道网络 = 蓝色**：1×1 的**圆角管段**，转弯处直接画成弧形；流向用蓝色小箭头表示。

这个色系划分与 workflow 里「分成三张网」的思路一致，也说明可视化时**物品层与管道层必须是两个独立图层**。

## 2. 基段与源桩的连接（B-10）

第二张图给出了同一基地内的三种状态：

| 对象 | 位置 | 状态 |
|---|---|---|
| 仓库存取线源桩（4x4） | 左上 | 基准，四边各有一个连接口 |
| 仓库存取线基段（8x4） | 源桩左下方 | **已连接** |
| 仓库存取线基段（8x4） | 右上，独立放置 | **未连接**，顶部有红框标注 |

### 2.1 由图中量出的关系

- 已连接的基段，其**顶边与源桩的底边重合**（边贴边），而**不是**整齐对齐——基段的左边缘明显比源桩的左边缘更靠右。
- 也就是说：**连接沿一条边发生，且该边上两设备有正的共同长度**，两端不需要对齐。
- 未连接的基段单独摆放，被红框标为「未连接」，印证 R-004 的连通性要求是**硬约束且会被校验**。

### 2.2 建议的连接判定

两个设备「相连」当且仅当：

1. 占地矩形**边贴边**（沿一条边接触，不重叠）；且
2. 该边上的**共同长度 > 0**（至少共享一个格子）。

由此把 R-004 变成图论问题：以源桩为根，构建「基段—基段 / 基段—源桩」的邻接图，**所有基段必须与至少一个源桩连通**（直接或经其他已连通基段）。这也解释了为什么图中会单独给未连接的基段打红框。

> 注：上图的 `源桩` 是 4×4、`基段` 是 8×4，两者共用边的长度可以是 1~4 格。图中显示的共用长度约 2 格，说明**允许部分搭接**。

## 3. 建议的验证器用例

| # | 场景 | 期望 |
|---|---|---|
| 1 | 基段顶边与源桩底边重合、共享 2 格 | 合法 |
| 2 | 基段单独放置，不与任何源桩/已连通基段接触 | 非法（未连接） |
| 3 | 基段与另一基段首尾相接、共享 1 格 | 合法，且两个都归入同一连通分量 |
| 4 | 基段与源桩重叠 1 格（不是边贴边） | 非法（重叠） |
| 5 | 基段与源桩仅角点相触 | 非法（共同长度为 0） |
| 6 | 链式：源桩 → 基段A → 基段B | 合法，A、B 均连通 |
| 7 | 链式断开：源桩 → 基段A，基段B 只与基段C 相连 | B、C 非法 |

## 4. 符号辨认结果（已确认）

用户已确认形态判读，**对照表移入 `design/global-constraints.md` §2**，要点：

- **一入三出 = 分流器**；**三入一出 = 汇流器**；**一入一出 = 准入口**；**倒 U 形 = 桥**。
- **桥是 4 个端口**，让两条**正交**的线互不干扰地交叉——水平线走左右两口、垂直线走上下两口。物流桥与管道桥同构。
- 分流器的出口面、汇流器的入口面可以是 2 或 3，因此端口数是 3 或 4（与 R-013 一致）。
- 黄色斜纹圆点是**正在运输的物品**，不是设备。

统一端口模型：直段 / 弯段 / 准入口 = 2 端口；**桥 = 4 端口**；分流器 / 汇流器 = 3 或 4 端口。
